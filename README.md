\# Breast Cancer MLOps Project



This project uses a Breast Cancer dataset to build and evaluate machine learning classification models.



\## Dataset



The dataset contains 4024 records and 16 columns.



\## Machine Learning Models



\- Logistic Regression

\- Random Forest Classifier

\- XGBoost Classifier



\## Preprocessing



\- Missing value handling

\- Standard Scaling

\- One Hot Encoding

\- Train-Test Split



\## MLflow



MLflow is used for:



\- Experiment tracking

\- Model logging

\- Metrics logging

\- Model registration
